# TeGe TKA Sejarah

Aplikasi belajar web untuk persiapan TKA Sejarah SMA, berisi 5 buku dengan materi singkat dan 20 soal latihan per buku.

- Situs: tegetkasejarah.totogutomo.com
- Versi aplikasi saat ini: 1.1.0 (kandidat stabil, siap uji)
- Penyusun buku: Ikrimah Laily, S.Pd., Gr. dan Toto Gutomo, S.Pd., Gr., M.Pd., CPSS
- Pengembang aplikasi: Toto Gutomo, S.Pd., Gr., M.Pd., CPSS
- Footer: TeGe TKA Sejarah ©2026 | totogutomo.com

## Isi folder

| Lokasi | Isi |
|---|---|
| index.html, css/, js/ | Kode aplikasi (HTML, CSS, JavaScript murni, tanpa framework); js/alat.js (kode verifikasi, ZIP, suara), js/sertifikat.js (gambar sertifikat) |
| js/soal.js, js/materi.js | Data 100 soal dan materi singkat |
| assets/ | Latar Beranda, sampul buku |
| pdf/ | Lima berkas PDF buku (sumber unduhan) |
| fonts/ | Playfair Display dan Plus Jakarta Sans (dipakai); Lato (lama, tidak dipakai lagi) |
| icons/, manifest.webmanifest, sw.js | Pemasangan ke layar utama dan mode offline |
| docs/mockup/ | Mockup desain (Beranda, Soal, Pengaturan, Sertifikat) |
| docs/font-lisensi/ | Lisensi SIL OFL untuk Playfair Display dan Plus Jakarta Sans |
| docs/serah-terima.md | Catatan keputusan dan persiapan pembaruan kode berikutnya |

## Lisensi

Kode dan materi: milik penyusun. Huruf: Lato, Playfair Display, dan Plus Jakarta Sans berlisensi SIL Open Font License (lihat docs/font-lisensi/).
